# Guía de uso / User guide

## Español

Cinque acompaña una partida física; no representa fichas ni turnos. Al abrir la aplicación puedes crear una partida o ingresar el código de seis caracteres de una invitación. Un enlace compartido completa el código automáticamente. La persona que crea la partida es anfitriona y puede iniciarla cuando haya de dos a cuatro jugadores.

Durante la partida, cada persona anota únicamente sus propios puntos en múltiplos positivos de cinco. La membresía, los totales, el historial, los reportes, el ganador y el estado se actualizan automáticamente. Para cuestionar una anotación ajena, usa **Reportar**; solo quien la anotó puede aceptar una puntuación corregida o rechazar el reporte.

Al alcanzar la meta se muestra el primer ganador según el orden autoritativo del servidor. El anfitrión finaliza cuando no hay reportes abiertos. Si se necesita corregir después, solo el anfitrión puede reabrir y debe registrar un motivo; el evento queda en el historial de auditoría.

La interfaz inicia en español y tema oscuro. Los selectores superiores guardan idioma y tema únicamente en ese navegador. Una cuenta Google vinculada conserva el mismo UID y muestra partidas recientes. Una identidad anónima no ofrece recuperación entre dispositivos y sus partidas tienen retención de 30 días.

## English

Cinque accompanies a physical game; it does not model tiles or turns. Create a game or enter the six-character invitation code. A shared link pre-fills that code. The creator is the host and can start once two to four players are present.

During play, each person records only their own positive multiples-of-five score. Membership, totals, history, reports, winner, and lifecycle update automatically. Use **Report** on another player's entry; only the scorer can accept a corrected value or reject the report.

The first target crossing in server-authoritative order is shown as the winner. The host can finish once no report is open. If a later correction is necessary, only the host may reopen and must record an auditable reason.

Spanish and dark mode are the defaults. The top controls store language and theme only in that browser. A linked Google account retains its UID and exposes recent games. Anonymous identities are not recoverable across devices and their games have a 30-day retention window.
